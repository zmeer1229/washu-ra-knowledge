## Resource map

The programming page groups bulletin boards and door decorations, program planning, branding guidelines, and meeting agendas. These are separate topic pages in this repository.

## Planning tools available from the source

- RA CEM Folder: Community Engagement Model materials.
- SATools: intentional conversations (ICs) and program proposals, as labeled on the website.
- Program Summary Form: the linked program summary workflow.
- Reserve A Space: the room reservation service.
- Upload Photos from Programs: the program photo collection destination.

For shared folders and upload destinations, follow the authenticated source page rather than publicly distributing a shared access link. No files were uploaded or forms submitted.

## Timing

Consider the time of year and competing events when choosing when to engage residents. The website directs RAs to calendar resources to help with this planning.
